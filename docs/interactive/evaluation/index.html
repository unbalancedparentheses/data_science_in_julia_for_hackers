What stays fixed?

The model was fitted in Julia using training messages. These calculations use its validation error rates and leave the final test set untouched. Moving prevalence assumes the error rates within spam and legitimate mail stay fixed (label shift). Fractional counts are expectations. Each change selects the cheapest rule again; the first grid minimum wins ties.
